# Equipo 3 Devathon X 

## Proyecto Ouija Virtual - Frontend

App web donde el usuario escribe una pregunta y recibe una respuesta misteriosa, generada de forma pseudoaleatoria o mediante lógica programada. 
No requiere login ni sesiones. La respuesta se presenta con estética y animaciones que simulan una sesión de espiritismo.

Este proyecto es parte del [Devathon X](https://programacion-es.dev/devathon/), evento de desarrollo en equipo de la comunidad de [Programación en español](https://www.youtube.com/@programacion-es).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
